A basic Emacs config for people who are used to modern and more cursor focused editors like Kate, VSCode, Notepad++, Sublime and so many more.

| Key | Description |
|---|---|
| `<escape>` | Cancel/quit |
| `<f1>` | C-x prefix |
| `<f3>` | C-x r prefix |
| `<f5>` | Help prefix |
| `<f2> 1` | Maximize window |
| `<f2> 2` | Split vertically |
| `<f2> 3` | Split horizontally |
| `<f2> <left>` | Focus window left |
| `<f2> <right>` | Focus window right |
| `<f2> <up>` | Focus window up |
| `<f2> <down>` | Focus window down |
| `C-1`…`C-9` | Switch to tab N |
| `C-a` | Select all |
| `C-S-<left>` | Select word left |
| `C-S-<right>` | Select word right |
| `C-S-<up>` | Select paragraph up |
| `C-S-<down>` | Select paragraph down |
| `S-<right>` | Select char right |
| `S-<left>` | Select char left |
| `S-<up>` | Select line up |
| `S-<down>` | Select line down |
| `C-<left>` | Move word left |
| `C-<right>` | Move word right |
| `C-g` | Jump to line |
| `M-h` | Move char left (vim-style) |
| `M-j` | Move line down (vim-style) |
| `M-k` | Move line up (vim-style) |
| `M-l` | Move char right (vim-style) |
| `M-C-h` | Move word left (vim-style) |
| `M-C-l` | Move word right (vim-style) |
| `M-p` | Move line up |
| `M-n` | Move line down |
| `M-f` | Move char right |
| `M-b` | Move char left |
| `M-C-f` | Move word left |
| `M-C-b` | Move word right |
| `M-<up>` | Move line up |
| `M-<down>` | Move line down |
| `C-<delete>` | Delete word forward |
| `C-<backspace>` | Delete word backward |
| `C-S-k` | Delete whole line |
| `C-x` | Cut line/region |
| `C-c` | Copy line/region |
| `C-v` | Paste |
| `C-s` | Save file |
| `C-w` | Save and close |
| `C-n` | New file |
| `C-o` | Open file browser |
| `C-z` | Undo |
| `C-y` | Redo |
| `C-S-z` | Redo |
| `C-<return>` | Insert line below |
| `C-S-<return>` | Insert line above |
| `C-f` | Search forward |
| `C-r` | Query replace |
